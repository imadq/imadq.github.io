03 — Automating with AI

Models where rules break down, plain code where they don't.

Language and vision models are useful for the messy middle of a workflow: reading photos, parsing documents, drafting text. Everything they produce passes a check before it touches a system of record.

Vision models for product data

Photos in, structured fields out. Open vision-language models run locally, so product images become titles, attributes and descriptions at no per-call cost, and every field is schema-checked before it is used.

Ollama · Qwen3-VL · Python · schema validation

Document extraction

OCR reads the page, a language model fills the fields, rules validate them, and anything uncertain lands in a human queue. An audit trail is kept for every document that passes through.

OCR · LLM extraction · validation rules · exception routing

Agentic workflows with Claude Code

Coding agents that scaffold pipelines, run QA gates and maintain repos, with verification steps a person signs off on. This site was designed in Claude Design and built with Claude Code.
